# EduSphere API reference

> Generated by `npm run docs:api` from the route definitions — do not edit by hand.

289 endpoints under `/api`. Health checks live outside it: `GET /healthz` (process is up) and `GET /readyz` (the database answers and has its tables).

Two more endpoints are for the host, not for the web app. `GET /api/internal/cron` runs the background jobs where no timer does (see DEPLOYMENT.md); with `CRON_SECRET` set it requires `Authorization: Bearer <secret>`. `GET /api/internal/code-runner-check?token=…` runs a small program in every language and reports the result, as `POST /api/admin/code-runner/check` does for an administrator; the token is derived from `CRON_SECRET` (`npm run smoke` prints the address), and without it the endpoint answers 404.

## Conventions

- **Format** — JSON. Success: `{ "data": …, "meta"?: … }`. Failure: `{ "error": { "code", "message", "details"? } }`.
- **Authentication** — an HTTP-only session cookie set by `POST /api/auth/login`. There are no bearer tokens to store in the browser.
- **CSRF** — every request other than `GET`/`HEAD` must send the header `X-CSRF-Token` with the token returned by `POST /api/auth/login` or `GET /api/auth/session`, and must come from a trusted origin.
- **Validation** — `422 VALIDATION_ERROR` with `details.fields` (`{ field: message }`).
- **Access** — "signed in" endpoints still check membership: a class you do not belong to answers `404`, an action your role may not perform answers `403`. Role names in the tables are the roles allowed to call the endpoint at all.
- **Pagination** — `?page=1&pageSize=20`; the response carries `meta: { page, pageSize, total, totalPages }`.
- **Exports** — `?format=csv|xlsx|pdf` where an export endpoint exists.
- **Dates** — ISO 8601 in UTC. Calendar days and class times follow the institution time zone (setting `institution.timezone`, default `Asia/Manila`). A field of type `date-time` takes ISO 8601 text such as `2026-11-12T09:00:00+08:00`; where it may be `null`, sending `null` means "no date" and leaving the field out of a `PATCH` keeps what is stored. Anything else is refused.
- **Real time** — Socket.IO at `/socket.io`, authenticated by the same cookie. Events: `notification:new`, `message:new`, `message:read`, `message:deleted`, `attendance:update` (room `attendance:<sessionId>`, teachers only). A server that cannot push says so in the session (`runtime.realtime: false`); clients then ask again on a timer.

In the tables, `name?` marks an optional field and `= value` a default.
